## Booking Flow

Online booking flow:
1. Select weekday date.
2. Select package/play option.
3. Select generated time slot.
4. Fill customer details.
5. Submit booking request.

Packages:
- MINI: 30 minutes, $32
- POWER: 45 minutes, $45
- MASTER: 60 minutes, $55
- Upgraded Play 15 Min: 15 minutes, $15
- Upgraded Play 30 Min: 30 minutes, $20

Slot rules:
- Monday to Friday only.
- Online weekend booking is disabled.
- Operating hours: 9:00 AM to 4:00 PM.
- Slots are generated by selected package duration.
- Last slot always fits before 4:00 PM.
- Maximum capacity is prepared as 5 bookings per slot.

Online booking does not ask users to select machine/game names or cafe menu items.

## Backend/API Note

The website is connected to the existing Google Apps Script endpoint in:

`src/data/bookingConfig.js`

Current endpoint:

`https://script.google.com/macros/s/AKfycbz2YjonaQjCAQrE_dNoa2h-7tozAI6cGGnaGxUnrJvN_fX0O66JCNBmMwp6UYcfRar32w/exec`

Frontend booking payload includes:
- name
- phone
- email
- groupSize
- date
- slotTime
- packageName
- packagePrice
- playTime
- toastieChoice
- coffeeChoice

The toastie/coffee fields are sent blank for backend compatibility because the website no longer asks customers to choose those online.

Important backend check before final client launch:
- Apps Script GET availability should support `?date=YYYY-MM-DD`.
- Apps Script POST should save booking and return `{ "status": "success", "bookingId": "..." }`.
- If backend returns `slot_full`, frontend displays the correct inline error.

## Hostinger Static Upload

Upload only the contents of the `dist` folder, not the project source folder.

Upload from:

`dist/`

Required production files/folders:
- `.htaccess`
- `index.html`
- `logo-rc-cafe-v2.png`
- `assets/`
- `images/`
- `videos/`

Before uploading to Hostinger `public_html`, delete old stale files:
- old `assets/`
- old `images/`
- old `videos/`
- old `index.html`
- old `.htaccess`
- old logo files such as `logo.png`
- any old `index-*.js` or `index-*.css` files
- any uploaded `dist.zip`

Then upload the fresh contents of `dist/`.

Keep `.htaccess` visible and uploaded. It is required for direct URLs like:
- `/booking`
- `/menu`
- `/gallery`
- `/contact`

After upload:
- Open site in incognito.
- Hard refresh with Ctrl + F5.
- Test Home, Booking, Menu and Contact pages.
